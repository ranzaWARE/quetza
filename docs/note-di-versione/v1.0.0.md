Prima versione stabile del server. Appunti a mano con l'audio della riunione e la trascrizione, tutto sul server dell'organizzazione.

## Cosa c'è
- **Scrittura a mano** con la penna e la pressione, più pagine A4, forme, frecce, testo e immagini. Temi chiaro, scuro ed e-ink.
- **Audio sincronizzato**: riascoltando si illumina quello che stavi scrivendo. **Trascrizione** con Whisper in un container locale, divisa per chi parla.
- **Ricerca** su titolo, etichette, testo digitato e trascrizione. **Etichette** per filtrare la libreria.
- **Condivisione** con i colleghi (può vedere, può modificare, o tutti in lettura) e link pubblici con scadenza. Export in PDF.
- **Nessun salvataggio perso**: il lavoro resta sul dispositivo finché il server non l'ha ricevuto. Se due dispositivi o due colleghi salvano insieme, nessuna versione viene sovrascritta. Le note eliminate restano 30 giorni nel cestino.
- **Accesso** con account locali, LDAP / Active Directory o SSO con qualsiasi provider OIDC. Quetza fa solo da client, non installa nessun provider.
- **Amministrazione**: utenti, spazio massimo per utente, stato dei backup.
- **Backup** ogni notte, verificato, con copia su una cartella del NAS (`BACKUP_COPY_PATH`). Export e import completi per cambiare server.
- **App Android** per telefoni e tablet, anche e-ink Boox: release [android-v1.0.0](https://github.com/ranzaWARE/quetza/releases/tag/android-v1.0.0).

## Installare
```bash
git clone https://github.com/ranzaWARE/quetza.git
cd quetza
./installa.sh
```
Si entra con `admin` / `admin` e Quetza chiede subito una nuova password. La guida completa è nell'app, dal pulsante «?».

## Aggiornare
```bash
docker exec quetza node /app/backup.js
git pull
./installa.sh
```
Il database si aggiorna da solo all'avvio, senza perdere note, audio o link.

## Prima di metterla in produzione
- Certificato della CA aziendale in `certs/`: con il self-signed alcuni browser bloccano il microfono.
- `BACKUP_COPY_PATH` su una cartella del NAS, poi «Esegui backup adesso» dal pannello e un ripristino di prova.
- Una prova di accesso con AD o SSO e una registrazione con trascrizione da tablet.
