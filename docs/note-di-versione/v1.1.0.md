Le note anche senza server: l'app Android funziona da sola e, se la colleghi, sincronizza tutto con il server.

## Novità
- **App Android anche senza server**: l'interfaccia è dentro l'app e le note restano sul dispositivo (senza backup finché non colleghi un server). Release [android-v1.1.0](https://github.com/ranzaWARE/quetza/releases/tag/android-v1.1.0).
- **Sincronizzazione**: collegando un server, note, audio, etichette e cestino si sincronizzano nei due sensi. Se la stessa nota cambia in due posti nessuna modifica va persa: una delle due diventa una copia «(conflitto …)».
- **Dispositivi collegati**: ogni dispositivo ha il suo accesso, che si toglie dall'app o dal pannello di amministrazione («Scollega dispositivi»).
- **Accesso**: dopo il login (locale, LDAP o SSO) si torna alla pagina da cui si era partiti.
- Nuova impostazione `CLIENT_ORIGINS` per abilitare altre app client oltre ad Android, che è già abilitata.

## Aggiornare
```bash
docker exec quetza node /app/backup.js
git pull
./installa.sh
```
Il database si aggiorna da solo all'avvio. Le app Android 1.0 vanno aggiornate alla 1.1.

## Release automatiche
Da questa versione ogni modifica su `main` pubblica da sola la release del server (`v*`) o dell'app (`android-v*`), con la patch successiva.
